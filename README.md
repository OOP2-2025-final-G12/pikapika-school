# ピカピカ学園

Peewee ORM を使用した Flask Web アプリケーション

## セットアップ

```bash
# 依存インストール
pip install -r requirements.txt

# 起動
python app.py
```

http://localhost:5000 にアクセス

## 構成

- `models/` - Peewee モデル
- `routes/` - Flask ルート
- `templates/` - HTML テンプレート
- `static/` - CSS
- `pikapika.db` - SQLite データベース（自動作成）
